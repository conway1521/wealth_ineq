The Wealth Gini Atlas harmonizes authoritative published wealth inequality series — WID, HFCS, LWS, SCF, and DFA — into a single long-format panel. Every row carries explicit source priority and comparability tier metadata so users can filter by quality and methodology rather than guessing which series to trust.

Two versioned release products ship together. The Wealth Gini Atlas requires a non-null headline Gini; the Wealth Moments Atlas captures distributional moments (top-1%, top-10%, bottom-50% shares; mean and median wealth) for rows where no Gini is available — including DFA quarterly admin-anchored estimates and WID country-years that publish top shares only.

A third companion product, the US Long-Run Series, stitches DFA annual top-share data (1989–2025) with SCF triennial mean/median anchors into a single analysis-ready frame with explicit interpolation flags.

Comparability tier A: same survey family, strongly harmonized definition (HFCS, LWS, SCF). Tier B: same broad concept, different source machinery (WID, OECD). All tier-1 sources are used as the backbone; tier-2 sources are retained as additional rows for cross-checking.

Schema

Both products share the same column set. Every row identifies a geography (geo_id, ISO-3166-1 alpha-3), a reference year, a wealth concept, and a unit of analysis. Methodology columns (source_dataset, source_priority, comparability_tier, top_tail_flag, method_version) let users filter by source quality without hand-coding exclusions.
